02Why these edits mattered: three patterns

Each edit repaired a gap that the builder's offline checks could not see. Each pattern is now a lesson in the plan stage's table.

site-check.py passed offline. The defect lived in the generator's wrapper, which only a run executed. Gate each stored command on empty stderr from bash -n, then run it with bash -c.
