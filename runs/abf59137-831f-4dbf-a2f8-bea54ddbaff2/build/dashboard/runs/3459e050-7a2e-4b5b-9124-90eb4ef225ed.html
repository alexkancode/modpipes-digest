Brief
A potluck sign-up site for neighbourhood block parties. An organiser creates an event with a date, an address and dish slots (mains, sides, desserts, drinks). Guests claim a slot with a name and an optional photo of the dish, and everyone on the event page sees claims appear live without reloading. Organisers get a private edit link, no accounts. A neighbour's home-automation script must be able to read the claims list as JSON. Hundreds of events a year, a few dozen guests each. Playful, high contrast, works one-handed on a phone.
