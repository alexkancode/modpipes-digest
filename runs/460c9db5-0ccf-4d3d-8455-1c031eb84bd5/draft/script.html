Rules for filling it in

  • One idea per beat. If a line needs "and", split it or cut it.
  • Show each feature working; don't describe it.
  • Voiceover lines stay under 8 words, so each fits its 4–5 second beat.
  • Don't name competitors, and don't use any claim without a source and sign-off.
  • Use the colours and fonts in assets/brand.json, which are placeholders for now.
