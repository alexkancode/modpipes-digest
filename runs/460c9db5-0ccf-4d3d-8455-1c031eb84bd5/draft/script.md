# Launch video script

**Status:** Template. No product brief exists yet. Research, outline and assets all ran without a subject, so every `[BRACKET]` below is a slot to fill. No product facts or claims have been made up.

**Length:** 30 seconds · **Tone:** short and sharp · **Format:** 1920×1080, captions on, voiceover optional

## Slots

| Slot | Meaning | Matches asset text |
|------|---------|--------------------|
| `[PRODUCT]` | Product name, exact spelling | "Product Name" (title, end card) |
| `[PAIN]` | The viewer's problem, in their words, 6 words max | — |
| `[PROMISE]` | One-line tagline | "One-line tagline goes here" |
| `[FEATURE 1–3]` | Capability → visible result, 4 words each | "Role or feature callout" (lower third) |
| `[CTA URL]` | Where to go | "call-to-action.example.com" |
| `[DATE]` | Launch date | "Launches [date]" |

## Rules for filling it in

- One idea per beat. If a line needs "and", split it or cut it.
- Show each feature working; don't describe it.
- Voiceover lines stay under 8 words, so each fits its 4–5 second beat.
- Don't name competitors, and don't use any claim without a source and sign-off.
- Use the colours and fonts in `assets/brand.json`, which are placeholders for now.
