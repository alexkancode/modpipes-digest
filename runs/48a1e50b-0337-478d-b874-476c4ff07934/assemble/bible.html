Open questions

  1. Is the open, unauthenticated upload intended? Who removes an unwanted photo?
    Context

    POST /upload accepts any visitor's files (app/routes/upload.tsx:17-21) and no route deletes or moderates images. Identity is none, so the bible has no signed-out detour to describe.

  2. After uploading, does the contributor know to click 'Gallery' in the nav?
    Context

    The result panel shows counts only and no link to /gallery (app/routes/upload.tsx:54-67).

  3. Which screen is meant to be the landing page: home or gallery?
    Context

    Home sits at '/' but nothing links to it (app/components/Nav.tsx:3-6). GALLERY.md says the nav was trimmed to Gallery and Upload. The guest persona most likely arrives through a shared /gallery link, which the code cannot confirm.

  4. What does a person see when saving a pick fails?
    Context

    insertSelection at app/routes/api.selections.tsx:40 has no try/catch. A fetcher action error may bubble to the root ErrorBoundary (app/root.tsx:54) and replace the page, or be silent. The code does not show which, and no test covers it.

  5. Should a search outage look different from 'No results'?
    Context

    A 502 from /api/music-search returns empty lists (app/routes/api.music-search.tsx:25-26), so the combobox shows 'No results' (app/components/MusicSearchCombobox.tsx:156-160). A network error is not caught at all (MusicSearchCombobox.tsx:35-44).

  6. Why does the visualizer default to the Spotify source when it rarely has a preview?
    Context

    app/components/AudioVizStage.tsx:22 defaults to 'spotify'. features/liquid-equalizer/feature.md:33-37 calls Spotify a bonus and file or mic the dependable paths.

  7. How does a visitor recover after denying microphone permission?
    Context

    The page only says 'Microphone permission was denied.' (app/components/AudioVizStage.tsx:110) and gives no retry guidance.

  8. Disagreement: features/site-nav/feature.md says the nav links Home and Fonts; the code links Gallery and Upload.

    features/site-nav/feature.md:7,14 vs app/components/Nav.tsx:3-6 and tests/e2e/nav.spec.ts:3-13. The test agrees with the code.
