    Here is the understanding. A pipeline named 'Run digest' takes a period variable (for example 2026-11-01..2026-11-06). A script gathers every run started in that period from `runs --json`: pipeline name, your typed variables, status, timings, usage, starred outputs. For each done run, the starred outputs are copied into a public GitHub Pages repo under alexkancode (one folder per run, created once by gh if missing) and pushed, so every site, game, image, video and markdown has a public URL that works on any machine. A Playwright stage screenshots each run's primary output as a hero image. A writer stage composes one HTML digest email: a card per done run with name, ask, hero inline, and links to each output on Pages, followed by one line each for failed and cancelled runs. A sender stage mails the digest through the Gmail connector to alexandrab@phase2online.com, with the markdown writeups attached under 25 MB. The digest HTML itself is also pushed to Pages as that period's index page and starred as the run's output.
