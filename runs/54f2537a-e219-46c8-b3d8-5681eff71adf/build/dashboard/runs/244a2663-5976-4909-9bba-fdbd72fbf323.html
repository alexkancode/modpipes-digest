Result: ~/Documents/Pinterest/<board>/<pin-id>.<png|jpg|mp4> holds clean copies of every image and video pinned to every board on your Pinterest profile, and the modpipes topic table lessons__pinterest_media holds one row per file with local path, board, pin title, Claude-written tags and description, media kind, pin id, and sha256. No Pinterest URL is stored anywhere. How: (1) preflight checks Firefox, xdotool, pyatspi and clamscan, and stops with a clear message if any is missing; (2) a driver focuses your logged-in Firefox, reads the accessibility tree, lists your boards, scrolls each board, and collects pin ids, titles and media sources into a working file, skipping ids already in the table; (3) a downloader fetches each pin's full-size media into ~/Documents/Pinterest, capped by max-pins-per-board; (4) a scanner runs clamscan, verifies bytes with Pillow or ffprobe, re-encodes images clean, and deletes only failures or hash duplicates by exact resolved path inside ~/Documents/Pinterest, never via rm, never with wildcards; (5) a describer looks at each clean file and writes tags plus a description; (6) a cataloguer adds rows to the table; (7) a report lists captured, skipped, quarantined and deleted items. Variables: pinterest-username, max-pins-per-board. You keep hands off the keyboard and mouse while the driver stage runs.
